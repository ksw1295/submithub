자동 채점 설정

채점 실행기를 쓸 수 있습니다 (docker). 제출 코드는 네트워크가 막힌 격리 컨테이너에서만 실행됩니다.
채점 사용 불가 — 이 서버에서 Docker 를 쓸 수 없습니다. 설정과 테스트 케이스는 등록해 둘 수 있지만, Docker 가 켜지기 전까지는 제출물이 채점되지 않고 "채점 불가"로 표시됩니다. (제출·리뷰·diff 등 나머지 기능은 그대로 동작합니다.) Docker 를 켠 뒤 아래 "모든 제출 다시 채점"을 누르세요.
실행 설정
Java: 기본 패키지의 main 이 있는 파일(예: Main.java), Python: main.py. zip 안의 경로는 그대로 씁니다.
설정과 테스트 케이스가 모두 있어야 자동 채점이 켜집니다.
테스트 케이스 추가
줄 끝 공백, 줄바꿈 종류(CRLF/LF), 끝의 빈 줄 차이는 무시하고 나머지는 정확히 비교합니다.
공개: 학생에게 입력·기대 출력·실제 출력을 보여줌. 비공개: 통과/실패만 보여줌.
