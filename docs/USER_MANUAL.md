## 2. 교수자 (Professor) 사용 설명서

### 2.1. 강의 개설 및 수강생 관리
1. 상단 네비게이션에서 **[강의 개설]** 버튼을 클릭합니다.
2. 강의명(예: `운영체제`)과 학기(예: `2026-2`)를 입력하고 생성합니다.
3. 강의 상세 페이지 상단에 발급된 **초대 코드**를 학생들에게 공유합니다.

### 2.2. 과제 등록 및 자동 채점 설정
1. 강의 상세 화면에서 **[과제 등록]** 버튼을 누릅니다.
2. 과제명, 상세 설명, 마감 일시, 지각 제출 허용 여부를 설정합니다.
3. *(선택)* **뼈대 코드(Baseline Code)**: 학생들이 시작할 기본 템플릿 코드를 입력하거나 파일을 첨부합니다. 이 코드는 향후 표절 검사 시 자동 제외됩니다.
4. 과제 등록 후 **[자동 채점 설정]**에서 언어(Java/Python), 메인 실행 파일명, 제한 시간/메모리, 테스트 케이스(입력값, 기대 출력값, 배점)를 등록합니다.

### 2.3. 라인 코드 리뷰 작성 (핵심 기능)
1. 과제 상세 화면의 학생 제출 목록에서 원하는 학생의 제출물(예: `v1`)을 클릭합니다.
2. 좌측 파일 트리에서 리뷰할 소스코드 파일을 선택합니다.
3. 코드 줄 번호를 마우스로 드래그하여 **줄 범위**를 선택합니다.
4. 하단에 열리는 입력창에 피드백을 작성하고 **[코멘트 등록]**을 누릅니다.

### 2.4. 표절 검사 (Winnowing) 실행 및 분석
1. 과제 상세 화면에서 **[표절 검사]** 탭을 클릭합니다.
2. 기준 유사도(기본값: `60%`)를 입력하고 **[검사 실행]** 버튼을 누릅니다.
3. 유사도 순으로 정렬된 학생 쌍(Pair) 목록에서 **[비교 보기]**를 누르면, 두 학생의 코드가 좌우로 나란히 뜨며 겹치는 로직이 노란색으로 하이라이트됩니다.

### 2.5. 통계 대시보드 확인
1. 강의 상세 화면에서 **[통계 보기]** 버튼을 클릭합니다.
2. Chart.js 기반의 **마감 직전 24시간 제출 분포**, **시간대별 제출 현황**, **학생별 점수 및 피드백 반영률 요약표**를 한눈에 확인할 수 있습니다.

## 3. 학생 (Student) 사용 설명서

### 3.1. 강의 수강 신청
1. 상단 네비게이션에서 **[수강 등록]**을 클릭합니다.
2. 교수에게 전달받은 **초대 코드**(예: `DEMO2026`)를 입력하면 즉시 강의에 등록됩니다.

### 3.2. 과제 제출 (두 가지 방법)
과제 상세 화면에서 다음 중 원하는 방식으로 제출할 수 있습니다:

* **방법 A: 파일 직접 업로드**
  * `.java`, `.py` 등 단일 파일이나 전체 프로젝트가 압축된 `.zip` 파일을 드래그 앤 드롭합니다.
* **방법 B: GitHub 커밋으로 제출 (추천)**
  * [GitHub 커밋으로 제출] 탭을 선택합니다.
  * 공개 GitHub 저장소 주소(예: `https://github.com/아이디/레포명`)와 브랜치명(예: `main` 또는 `v1`)을 입력하고 제출합니다.

### 3.3. 피드백 확인 및 재제출 (성장 타임라인)
1. 내 제출 상세 화면에서 교수가 남긴 **라인 피드백 코멘트**를 확인합니다.
2. 코멘트를 참고하여 코드를 수정한 뒤, 동일한 방식으로 다시 제출합니다.
3. 새 버전(v2)이 등록되면, 시스템이 자동으로 **"반영됨(REVISED)"** 뱃지를 달아주며 나의 **피드백 반영률(%)**이 갱신됩니다.
4. **[버전 비교(Diff)]** 버튼을 누르면 v1과 v2 사이에서 내가 무엇을 고쳤는지 좌우 분할 화면으로 직접 대조할 수 있습니다.

## 4. 캡스톤 심사용 3분 현장 시연 퀵 스타트

발표 현장에서 심사위원들에게 가장 강력한 인상을 남길 수 있는 **3분 시연 루트**입니다:

```text
[1분: 인공지능 프로젝트 실제 검증 시연]
1. 'prof2' (비번: prof1234!)로 로그인
2. 강의 목록에서 [인공지능 및 기계학습] 클릭 -> 과제 1 클릭
3. 이민준(student1) 학생의 'v1 (78점)' 클릭 (http://localhost:8080/submissions/13)
   -> 실제 GitHub(univ-rag-chatbot) 파일 트리와 교수 피드백 코멘트 3건 보여주기!
4. 상단 [이민준 학생 제출 이력] 클릭 (http://localhost:8080/assignments/5/students/2)
   -> 하이라이트: "교수의 3개 피드백이 v2에서 100% 완벽 반영됨!" 카드 보여주기!
5. [v1 ↔ v2 버전 비교] 클릭 -> 실제 파이썬 코드 개선 Diff 시연

[2분: 자료구조 과제 표절 검사 및 샌드박스 시연]
1. 'prof' (비번: prof1234!)로 전환 로그인
2. [자료구조] 강의 -> 과제 1 [표절 검사] 클릭 (http://localhost:8080/assignments/1/similarity)
   -> Winnowing 알고리즘으로 적발된 최지호 ↔ 박서연 93.3% 표절 결과 확인
3. [비교] 클릭 -> 좌우 2분할 화면에서 겹치는 코드가 노란색으로 실시간 하이라이트되는 화면 시연!
4. [과제 1 상세]로 돌아가 Docker 격리 자동 채점 결과(14/14 통과) 확인
```
