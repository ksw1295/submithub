어떻게 동작하나요?

과제 제출부터 피드백 반영까지, 실제 소프트웨어 개발팀의 코드 리뷰 흐름을 구현했습니다.

1

과제 제출 (v1)

학생이 소스 파일, ZIP 또는 GitHub 공개 커밋 SHA를 제출하면 v1 버전이 생성되고 Docker 컨테이너에서 즉시 컴파일·채점됩니다.

2

줄 단위 코드 리뷰

교수는 코드 뷰어에서 개선이 필요한 특정 줄을 클릭하여 인라인 피드백을 작성하고 점수와 함께 전달합니다.

3

피드백 수정 후 제출 (v2)

학생은 지적받은 사항을 확인하고 코드를 보완하여 v2 버전을 다시 제출합니다. 버전별 diff 비교도 지원됩니다.

4

반영 여부 자동 판정

시스템이 Myers Diff로 줄 위치 변화를 분석하여 🔴미반영, 🟢반영됨, ⚪삭제됨을 자동 판정하고 반영률을 산출합니다.

핵심 기능 둘러보기

기존 LMS 과제방의 한계를 넘는 최신 개발자 지향 기능들을 제공합니다.

Git 스타일 버전 관리

제출할 때마다 v1, v2 번호가 자동으로 부여되며 이전 버전을 덮어쓰지 않고 타임라인으로 보존합니다. GitHub 커밋 연동과 마감·지각 처리를 지원합니다.

줄 단위 인라인 코드 리뷰

전체 총평 대신 문제가 있는 정확한 코드 줄에 코멘트를 남깁니다. 교수와 학생 간의 질의응답 스레드를 통해 깊이 있는 코드 지도가 가능합니다.

피드백 반영 자동 추적

교수가 일일이 이전 코멘트와 새 코드를 대조할 필요가 없습니다. Myers Diff 기반 줄 추적으로 반영률(%)과 남은 피드백 개수를 실시간으로 제시합니다.

MOSS 기반 표절 검사

Stanford MOSS와 동일한 Winnowing 알고리즘으로 변수명 치환, 주석 추가, 공백 변경 등의 꼼수를 무력화합니다. 의심 쌍은 나란히 하이라이트 비교를 제공합니다.

Docker 격리 자동 채점

네트워크가 차단되고 자원이 제한된 안전한 Docker 컨테이너에서 Java 및 Python 코드를 실행합니다. 버전별 테스트 케이스 통과율 추이를 보여줍니다.

제출 통계 대시보드

강의별 제출률, 미제출자 명단, 지각 비율 및 마감 직전 24시간 제출 집중도 그래프와 학생별 버전 수·반영률을 시각화 차트로 제공합니다.
