🎓 교수용 SubmitHub 핵심 이용 가이드 💻 학생용 SubmitHub 핵심 이용 가이드

SubmitHub는 Git 버전 관리 기반의 코드 과제 제출 및 자동 채점·인라인 피드백 플랫폼입니다.

1단계 강의 개설 & 초대 코드 배부
상단 네비게이션의 강의 개설 버튼을 클릭하여 강의를 등록합니다.
생성된 강의 상세 페이지에 표시되는 8자리 초대 코드를 학생들에게 공유해 수강 등록을 받습니다.
2단계 과제 등록 및 자동 채점 설정
강의 페이지에서 과제 등록을 눌러 기한과 지각 허용 여부를 설정합니다.
과제 등록 후 자동 채점에서 언어와 입출력 테스트 케이스를 등록하면 학생 제출 시 Docker 격리 환경에서 즉시 자동 채점됩니다.
3단계 줄 단위 코드 리뷰 & 피드백 추적 (LineTracker)
학생 제출물을 클릭하여 소스코드 화면에서 지적하고 싶은 코드 줄 번호를 클릭해 피드백 코멘트를 남깁니다.
학생이 수정본을 재제출하면 LineTracker가 수정 여부(반영됨/미반영)를 자동으로 추적해 표시합니다.
4단계 과제 관리 (실수 취소 및 표절 검사)
• 과제 삭제: 실수로 잘못/중복 등록한 과제는 학생 제출물이 0건일 때 과제 삭제 버튼으로 안전하게 삭제할 수 있습니다.
• 표절 검사: 마감 후 표절 검사 버튼으로 학생 간 코드 유사도(Winnowing 알고리즘)를 1클릭으로 분석합니다.

SubmitHub를 통해 과제를 Git 커밋처럼 버전별로 제출하고 실시간 코드 검증 및 교수 피드백을 받을 수 있습니다.

1단계 수강 등록
상단 네비게이션의 수강 등록 버튼을 누르고 교수님께 받은 8자리 초대 코드를 입력합니다.
2단계 과제 제출 (파일 / GitHub)
• 과제 페이지에서 소스코드 파일이나 ZIP 파일(최대 10MB)을 업로드하거나, GitHub 공개 저장소 주소를 입력합니다.
• 제출할 때마다 새 버전(v1, v2...)이 생성되며 이전 버전은 그대로 안전하게 보관됩니다.
3단계 테스트 결과 및 교수 리뷰 확인
제출 즉시 안전한 Docker 격리 환경에서 테스트 케이스가 실행되어 점수와 통과율을 확인할 수 있습니다.
교수님이 특정 코드 줄에 피드백 코멘트를 남기면 알림과 함께 소스코드 뷰어에서 바로 확인할 수 있습니다.
4단계 수정 후 재제출 (피드백 반영)
교수님의 지적 사항을 수정한 뒤 다시 제출하면, 이전 버전과 이번 버전의 변경점(Diff)과 함께 피드백이 잘 반영되었는지(🟢 반영됨)가 자동으로 판정됩니다.
