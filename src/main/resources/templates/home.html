Interactive Workflow

스크롤을 내리면 코드 리뷰의 전 과정이 펼쳐집니다

단순히 파일만 올리고 끝나는 과제방이 아닙니다. 제출부터 자동 채점, 인라인 리뷰, 재제출 추적까지 실제 개발팀의 PR 워크플로우가 그대로 돌아갑니다.

STEP 01 · SUBMIT & SANDBOX

파일·ZIP 또는 GitHub 커밋 제출과 즉시 격리 채점

학생이 소스 파일이나 GitHub 공개 저장소 커밋 SHA를 제출하면 v1 스냅샷이 생성됩니다. 동시에 네트워크가 차단된 Docker 컨테이너에서 공개·비공개 테스트 케이스를 자동 실행합니다.

STEP 02 · INLINE CODE REVIEW

줄 번호를 클릭해 남기는 정확한 코드 피드백

교수는 코드 뷰어 또는 Diff 화면에서 특정 줄(또는 Shift+클릭 범위)을 바로 선택해 코멘트를 남깁니다. 학생과 교수는 해당 줄 아래에서 스레드로 질의응답을 이어갈 수 있습니다.

STEP 03 · ITERATE & DIFF

피드백을 반영한 v2 재제출과 좌우 분할 Diff

이전 버전을 덮어쓰지 않고 v2, v3가 타임라인으로 쌓입니다. 좌우 분할(Split) 및 통합(Unified) Diff 뷰어로 어느 줄이 어떻게 고쳐졌는지 한눈에 대조합니다.

STEP 04 · AUTO-TRACKING & AI JUDGE

Myers Diff 줄 추적 + Gemini AI 해결 여부 판정

교수가 이전 코멘트를 일일이 다시 찾아볼 필요가 없습니다. 다른 줄에 코드가 추가되어 줄 번호가 밀려도 Myers Diff가 원래 코멘트 위치를 추적하고, AI가 실제 해결 여부를 한 번 더 검증합니다.
